# Staffing Billing Desk

Single-page prototype of a staffing billing app: timesheets, invoices & payments, payroll and pay history, commission, direct hires, clients & settings, and reports.

Everything lives in `index.html` (plain HTML, CSS and JavaScript, no build step). Data entered in the app is saved in the browser's localStorage.

Live: https://himanshuuniqueit.github.io/staffing-billing-desk/
